# BBB Internal Document Formats

Documents in this directory should read like internal business records from
BBB: terse, procedural, and lightly bureaucratic.

Use transaction IDs, department labels, audit notes, and mundane operational
language. Treat strange events as accounting, logistics, compliance, or receipt
exceptions. Redact sensitive names with `[REDACTED]`.
